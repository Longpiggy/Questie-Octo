# Questie-Octo project identity

## Canonical project

The canonical Questie-Octo repository designated by the project maintainer is:

- https://github.com/SandreaSub/Questie-Octo

Copies, mirrors, package caches, downstream forks, and modified versions hosted
elsewhere are independent unless the canonical project explicitly says
otherwise. A downstream maintainer choosing to mirror or host a fork on an
OctoWoW, GitHub, Gitea, GitLab, or other service does not by itself create an
affiliation, endorsement, partnership, or ownership relationship with the
canonical Questie-Octo project.

## Compatibility is not affiliation

Questie-Octo targets and references software and game environments including
World of Warcraft, Turtle/Octo WoW clients, ClassicAPI, Questie, pfQuest, pfUI,
Ace3-family libraries, and other compatibility references documented in the
repository. Compatibility, testing, source comparison, or reference use does
not imply endorsement by or affiliation with those projects or their
maintainers.

World of Warcraft and Blizzard Entertainment names, marks, and game assets
remain the property of their respective rights holders. Other project names
and trademarks remain the property of their respective owners.

## Support boundary

Questie-Octo maintainers are responsible only for the canonical Questie-Octo
code and releases they publish. Downstream forks may change gameplay behavior,
features, licensing notices, packaging, or support expectations and should be
treated as separate projects.
